# Plantilla de presentación con fondo de partículas

### Configuración de la presentación

- Guarda en la carpeta /static las imágenes que se utilizarán como diapositivas
de la presentación.

- El formato de las imágenes debe ser siempre PNG.

- Las imágenes deben tener un tamaño de 1200px×1125px.

- Nombra las imágenes con una numeración secuencial que comience en 1.png.

- El script detecta automáticamente el número de diapositivas. Por ejemplo, si
existen 1.png, 2.png y 3.png, se mostrarán 3 diapositivas en ese orden.
